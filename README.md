# Tali Rimba: Monyet & Buaya 🐒🐊

Game platformer co-op 2 pemain real-time via WebRTC (PeerJS) berbasis static HTML & Canvas. Siap di-deploy langsung ke Vercel.

## Fitur
- **2 Pemain Real-time**: P2P langsung antar browser (tanpa server backend).
- **Fisika Tali Elastis**: Monyet dan Buaya terikat bersama.
- **Mobile Responsive**: Kontrol tombol sentuh di layar ponsel & keyboard di PC.

## Kontrol
- **Kiri/Kanan**: A / D atau tombol ◀ / ▶
- **Lompat**: W / Spasi atau tombol ▲
